# 🕐 Ora se dă înapoi

Aplicație interactivă pentru lecția din **25 octombrie 2026**, ziua în care ceasurile din Marea Britanie trec de la **02:00 BST la 01:00 GMT**. E gândită pentru Eva (Year 3–4, sistemul britanic) și pentru profesorul care o folosește în sesiune. Merge **offline** (dublu-click pe `index.html`), e **bilingvă RO / EN**, are temă deschisă și întunecată și merge pe telefon, tabletă și calculator.

## Fizica din spatele aplicației

- **Poziția Soarelui**: algoritmul NOAA / Almanahul astronomic de precizie mică. Folosește anomalia medie, ecuația lui Kepler, longitudinea ecliptică, declinația, ascensiunea dreaptă, timpul sideral și unghiul orar. Eroarea e de aproximativ 1 minut la răsărit și apus.
- Verificare pentru Londra: 24 oct 2026, răsărit **07:39 BST** / apus **17:48 BST**. 25 oct 2026, **06:41 GMT** / **16:46 GMT**. 21 iun 2026, **04:42** / **21:21 BST**. 21 dec 2026, **08:03** / **15:53 GMT**.
- Răsăritul și apusul se calculează la −0,833°, adică cu refracția atmosferică și raza discului solar, ca în tabelele oficiale.
- **Planetele modificate** folosesc aceleași formule, cu parametrii tăi. Ca planeta să nu sară din loc când miști un slider, modelul se re-ancorează în clipa curentă. Ziua solară se calculează din rotația siderală și din an: 1/zi = sens/rotație − 1/an.
- **Eclipsele** folosesc razele reale (Soare 696 000 km, Lună 1 737 km, Pământ 6 378 km). Distanța Pământ–Lună merge de la 356 500 la 406 700 km, iar distanța până la Soare variază după lună. Umbra Pământului la distanța Lunii e (π☾ + π☉ − r☉) × 1,02, ca în almanahuri. Pe glob, shaderul calculează pentru fiecare punct cât din discul Soarelui e ascuns de Lună (aria de suprapunere a două cercuri).
- **Regula schimbării orei** (UE și UK): ultima duminică din martie și ultima duminică din octombrie, la **01:00 UTC**.
- Scena 3D e în cadrul eclipticii, fix față de stele. Axa e înclinată cu ε, iar precesia rotește axa în jurul polului eclipticii.

## Publicare pe GitHub Pages

1. Creează pe GitHub un repository gol numit `ora-se-da-inapoi`.
2. Din folderul aplicației:
   ```bash
   git init && git add . && git commit -m "Prima versiune"
   git branch -M main
   git remote add origin https://github.com/Beldugan/ora-se-da-inapoi.git
   git push -u origin main
   ```
3. *Settings → Pages → Source*: **GitHub Actions**. Pagina va fi la `https://beldugan.github.io/ora-se-da-inapoi/`.

Varianta din arhiva `.zip` are deja `.github/workflows/pages.yml` la locul lui. Dacă urci folderul de pe Windows, copiază `workflow-pages-yml.txt` în `.github/workflows/pages.yml`.
